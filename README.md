## Contents
The course parts folders are divided as follows:

0\. [**Basics of web applications**](https://github.com/manosmin/fullstackopen/tree/master/part0) -  Fundamental concepts and principles of web development.

1\. [**Introduction to React**](https://github.com/manosmin/fullstackopen/tree/master/part1) - Components, props, state, and event handling.

2\. [**Communicating with Server**](https://github.com/manosmin/fullstackopen/tree/master/part2) - REST APIs, Axios, and effect hooks.

3\. [**Programming a Server with Node.js and Express**](https://github.com/manosmin/fullstackopen_part3) - Backend basics, middleware, and MongoDB.

4\. [**Testing Express Servers, User Administration**](https://github.com/manosmin/fullstackopen/tree/master/part4) - Unit and integration testing, authentication, and security.

5\. [**Testing React Applications**](https://github.com/manosmin/fullstackopen/tree/master/part5) - Jest, React Testing Library, and E2E testing.

6\. [**State Management with Redux and TanStack Query**](https://github.com/manosmin/fullstackopen/tree/master/part6) - Redux and TanStack Query principles and implementation.

7\. [**React Router and Styling**](https://github.com/manosmin/fullstackopen/tree/master/part7) - Routing, navigation, and UI styling.

8\. [**GraphQL**](https://github.com/manosmin/fullstackopen/tree/master/part8) - Efficient data fetching with GraphQL, schema design, queries, and mutations.

9\. [**TypeScript**](https://github.com/manosmin/fullstackopen/tree/master/part9) - TypeScript basics, type annotations, interfaces, and generics.

11\. [**CI/CD**](https://github.com/manosmin/fullstackopen/tree/master/part11) - Create CI/CD pipelines and automated workflows using GitHub Actions to streamline build, test, and deployment processes.
